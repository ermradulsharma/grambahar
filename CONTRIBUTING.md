# Contributing to GramBahar

First off, thank you for considering contributing to GramBahar! It's people like you that make the project such a great tool for preserving traditional Bengal culture.

## 🚀 How Can I Contribute?

### Reporting Bugs

- Use the [GitHub Issues](https://github.com/your-username/grambahar/issues) tab.
- Describe the bug clearly and provide steps to reproduce.
- Include OS and browser details.

### Suggesting Enhancements

- Check if the feature has already been suggested.
- Open an issue with the "feature request" tag.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. Install dependencies: `npm install`.
3. If you've added code that should be tested, add tests.
4. Ensure the build passes: `npm run build`.
5. Issue that pull request!

## 📜 Style Guide

- Use **Prettier** for formatting.
- Follow the established **directory structure** (Category-wise grouping).
- Use **dynamic imports** for large admin modules.
- Ensure all new UI components are placed in the appropriate `src/components/ui` subfolder.

## 💬 Communication

If you have questions, please reach out via GitHub Discussions or open an issue.

Happy coding! 🍃
